# debug-info.json (major 1)

`debug-info.json` describes one build for a source-level debugger: its files, its POUs, every
variable of every scope with its IEC type, the instance tree, and (once probes exist) the
statement map. It is a host-side file: nothing in it is linked into the runtime image.

- Schema: [`debug-info.schema.json`](debug-info.schema.json) (JSON Schema draft-07).
- Produced by `compile()` as `CompileResult.debugInfo`; serialise it with `serializeDebugInfo()`
  (`src/backend/debug-info-gen.ts`), which sorts keys so equal inputs give equal bytes.
- It sits beside `debug-map.json` (`DebugMapV2`), which it does not change. Static storage is
  addressed through `debug-map.json` leaves; this file only says where each instance and global
  starts in them.

All names are upper-cased, as the compiler folds identifiers and as `debug-map.json` leaf paths
are written. IEC identifiers are case-insensitive, so a reader compares them that way.

## Versioning

| Field | Meaning |
|---|---|
| `format` | Always `"strucpp-debug-info"`. |
| `major` | `1`. A reader refuses any major it does not support and names both versions. Removing or re-meaning a field is a major bump. |
| `minor` | Additive changes only. Every object may carry properties the schema does not list; readers ignore what they do not know. |

`debug-map.json`'s own `version: 2` is a separate axis and does not move with this format.

## `build`

| Field | Meaning |
|---|---|
| `md5` | Program identity, the value served on the runtime's 0x45 request: the caller's `md5` option verbatim, or empty when the caller supplied none. |
| `buildId` | Build identity, SHA-256 (hex) over the compiler version, the canonical `options`, each source file's path and SHA-256, and each library's name, version and content hash. Computed from inputs, so it is known before code generation. |
| `compiler` | `"strucpp <version>"`. |
| `options` | The compile options that change generated code, with sorted keys. `debugProbes` is always present. |
| `time` | Optional and informational; never part of `buildId` or any compared byte. Not written today. |
| `probes` | `true` for a build compiled with debug probes, `false` otherwise. |

## `files`

One entry per user source file, in compile order. `id` is the index other tables use.

| Field | Meaning |
|---|---|
| `id` | Index of this file. |
| `path` | The file name passed to the compiler. |
| `sha256` | SHA-256 (hex) of the file's exact UTF-8 bytes. |
| `library` | Name of the library the file belongs to, or `null` for a user file. |
| `generated` | `true` when the whole file was generated by a tool. |

## `pous`

One entry per program, function block, function and method of the user source, then one per
library function block that the program instantiates (with no source).

| Field | Meaning |
|---|---|
| `id` | Index of this POU. |
| `name` | POU name. |
| `kind` | `program`, `fb`, `function` or `method`. |
| `owner` | For a method, the `id` of its function block; otherwise `null`. |
| `file` | `files[].id` of the declaring file, or `null` for a library POU. |
| `span` | `[startLine, startCol, endLine, endCol]` of the declaration, 1-based, or `null`. |
| `entryProbe` | First probe of the body. `null` until the statement map exists. |
| `noSource` | `true` when the POU has no source in this build. |
| `noSourceReason` | `library`, `binary` or `optout` when `noSource` is `true`, else `null`. |
| `cppSymbol` | Mangled C++ symbol of the body, or `null` when not recorded. |
| `generated` | `true` when the POU is marked as generated code. |
| `typeId` | For a program or function block, the `types[].id` describing its instance members; `null` for a function or method. |
| `locals` | Stack-resident variables (see below). |

### `locals`

Variables that live in the POU's frame, not in an instance: every variable of a function or a
method, and the `VAR_TEMP` variables of a program or function block.

| Field | Meaning |
|---|---|
| `name` | Variable name. |
| `typeId` | `types[].id` of its type. |
| `kind` | The var block it is declared in (`VAR`, `VAR_INPUT`, `VAR_OUTPUT`, `VAR_IN_OUT`, `VAR_TEMP`, `VAR_INST`). |
| `localsSlot` | Index into the POU's `__dbg_locals` offset table in `generated_debug.cpp`. `null` until probe builds emit that table. |

## Scopes: where each variable is described

| Scope | Described in |
|---|---|
| Program and FB `VAR`, `VAR_INPUT`, `VAR_OUTPUT`, `VAR_IN_OUT` | `members` of the POU's type, with `section` |
| `VAR_TEMP`, and every function and method variable | `locals` of the POU |
| `VAR_EXTERNAL` | `externals`, resolved to `globals` |
| `VAR_GLOBAL` | `globals` |

## `probes`

The statement map, columnar: index `i` of every array describes probe ID `i`. Empty until the
compiler plants probes.

| Field | Meaning |
|---|---|
| `pou` | `pous[].id` of the probe's POU. |
| `file` | `files[].id` of the probe's file. |
| `line` | First line of the statement, 1-based. |
| `col` | First column, 1-based. |
| `endLine` | Last line. |
| `endCol` | Last column. |
| `kind` | `0` statement, `1` loop condition, `2` ELSIF condition; `3` reserved. |
| `flags` | bit 0 generated, bit 1 library, bit 2 locked. |
| `origin` | Index into `origins`, or `-1`. |

## `lines`

Keyed by `files[].id` (as a string): the sorted lines that carry at least one probe. Empty until
the compiler plants probes.

## `types`

Each type is described once; variables and members refer to it by `id`.

| Field | Meaning |
|---|---|
| `id` | Index of this type. |
| `kind` | `elementary`, `string`, `array`, `struct`, `fb`, `enum`, `subrange`, `union` or `ref`. A program's instance type is described with kind `fb`; its POU says `program`. |
| `name` | Declared name (`INT`, `MOTOR`, `PCT`), or `null` for an anonymous type such as an inline `ARRAY[..] OF` or an inline enumeration. |
| `members` | For `struct`, `fb` and `union`: the members in declaration order. |
| `dims` | For `array`: `[low, high]` per dimension, outermost first; `null` for a variable-length `*` dimension. |
| `elem` | For `array`: `types[].id` of the element type. |
| `values` | For `enum`: `[name, value]` pairs in declaration order. |
| `length` | For `string`: declared capacity in characters (254 when undeclared). |
| `wide` | For `string`: `true` for WSTRING. |
| `base` | For `subrange` and `enum`: `types[].id` of the base type. For `fb`, the type it `EXTENDS` is in `extends`. |
| `range` | For `subrange`: `[low, high]`. |
| `target` | For `ref`: `types[].id` of the referenced type, or `null` when it is an interface or unknown. |
| `refKind` | For `ref`: `ref_to`, `reference_to`, `pointer_to`, or `interface` for a variable of an interface type. |
| `extends` | For `fb`: `types[].id` of the base function block, or `null`. |
| `opaque` | `true` for a library struct whose fields the library does not export; `members` is then empty. |

### `members`

| Field | Meaning |
|---|---|
| `name` | Member name. |
| `typeId` | `types[].id` of its type. |
| `section` | Var block of an `fb` member (`VAR`, `VAR_INPUT`, `VAR_OUTPUT`, `VAR_IN_OUT`); `null` for a struct or union field. |
| `location` | The `AT` address (`%QW0`), or `null`. |
| `format` | Index into `formats`, or `null`. |

A library function block is a black box: its members are its interface (`VAR_INPUT`,
`VAR_OUTPUT`, `VAR_IN_OUT`), as in `debug-map.json`.

## `instances`

Columnar: index `i` of every array describes one instance. Program instances come first, each
followed depth-first by the function-block instances it contains (members, inherited members,
array elements, and fields of structs), then global function-block instances. `VAR_IN_OUT`
members refer to an instance owned elsewhere and are not walked.

| Field | Meaning |
|---|---|
| `path` | Instance path, as in `debug-map.json` leaf paths: `PROG0`, `PROG0.MOTOR1.PID`, `PROG0.AXES[2]`. Global FB instances use the bare global name. |
| `typeId` | `types[].id` of the instance's type. |
| `leafBase` | Index in `debug-map.json` `leaves` of the instance's first leaf, or `null` if it has none. A member's leaf is `leafBase` plus its ordinal in the type's leaf order. |
| `leafBaseExt` | First leaf of the instance's sections that `debug-map.json` does not yet cover, appended after every existing leaf (the second leaf pass). `null` until that pass exists. |

## `globals`

| Field | Meaning |
|---|---|
| `name` | Global name. |
| `typeId` | `types[].id` of its type. |
| `location` | The `AT` address, or `null`. |
| `leafBase` | Index in `debug-map.json` `leaves` of its first leaf, or `null`. |

## `externals`

One entry per `VAR_EXTERNAL` declaration.

| Field | Meaning |
|---|---|
| `pou` | `pous[].id` declaring it. |
| `name` | Variable name. |
| `global` | Index into `globals` of the storage it refers to, or `null` if no global of that name exists. |

## `origins`

Graphical-language source references (LD/FBD), referenced from `probes.origin`. Empty today.

| Field | Meaning |
|---|---|
| `pou` | Graphical POU name. |
| `kind` | `rung`, `element` or `block`. |
| `id` | The editor's element identifier. |

## `formats`

Per-variable display formatters from declaration attributes, referenced by `members[].format`.
Empty today.
